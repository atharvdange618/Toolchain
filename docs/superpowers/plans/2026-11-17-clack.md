# Clack migration implementation plan

This plan records the initial Clack migration. The [async CLI progress plan](2026-11-17-async-cli-progress.md#release-verification-2026-11-21) records the later cancellation behavior, CI results, and v3.0.0 release.

**Goal:** Give Toolchain consistent prompts and terminal output with Clack.

**Design:** Replace `prompts` with `@clack/prompts`, retain Commander and picocolors, and require Node >=20.12.0. Use Clack output only on terminals, keeping plain output for redirected commands. Preserve doctor reports, JSON, update choices, retry commands and exit codes. Keep subprocess output visible and use static progress because subprocesses block the event loop. Scaffold owns its opening and completion messages, suppressing init's nested summary.

**Approaches:** Prompt-only replacement leaves the mixed output and duplicate summaries. Replacing the command parser adds unrelated work. The chosen scope replaces prompts and tidies human-facing output using the existing logger.

**Scope:** package.json, pnpm-lock.yaml, CI runtime comment, README runtime requirement; init/scaffold/update-prompts and their tests; logger and its tests. Existing generator output and manifests stay unchanged. Issue #11's helper, four tests and docs belong to its separate fix branch; the Clack branch starts from main.

**Tech stack:** TypeScript 7, Commander 13, Clack 1.9, Vitest 4.

No dependency additions beyond the approved Clack replacement. The user requested separate commits for issue #11 and Clack.

1. [x] Replace prompts and declare the runtime floor → verify published metadata, cancellation, default choices, flag bypass and no-terminal tests.
2. [x] Use Clack output through the logger and remove nested summaries → verify terminal/plain streams, stderr errors and scaffold/init completion behavior.
3. [x] Verify the complete CLI → lint, typecheck, full tests, format check on changed files, build, doctor JSON and terminal prompt checks.

## Validation notes from the initial migration

- Clack 1.9.0 published metadata requires Node >=20.12.0.
- The configured task tracker returned HTTP 404 twice; use this checklist.
- Reference docs were absent under .codex/docs; matching .claude/docs copies were read.

- Combined suite before branch separation: 612 tests passed, 2 skipped. Build and formatting checks passed. Doctor JSON contains 66 entries, parses as one document and exits 0; the text report needs no action.
- The reviewer found hidden prompts when only stdin was a terminal. Three failing regressions reproduced it; checking both streams fixed it. Scoped re-review found no further issues.
- Built Windows terminal checks: init/scaffold cancellation exit 0, update cancellation exits 1; cancellation writes no setup files. The sandbox terminal also hangs for built-in Node readline, while the real terminal exits normally. No workaround was added.
- Preserved existing picomatch resolutions after pnpm's unrelated deduplication; frozen-lockfile installation passed.
- The network scaffold smoke matrix and exact Node 20.12 runtime were not exercised. No publish was made.
- After separation, `fix/11-uninstall-eslint-first` contains only issue #11 (`a9fe43f`). `allmight/clack-cli` starts from main, excludes that commit, and passes lint, typecheck, formatting and all 608 tests (2 skipped).
